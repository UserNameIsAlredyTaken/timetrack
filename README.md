# Время — трекер недели

Простое приложение для телефона: понять, сколько часов в неделю уходит на разные дела.

## Как пользоваться

- **Добавить**: нажать категорию, потом количество часов (1–8). Запись сохраняется сразу, в текущий день.
  - «точнее» под кнопками: ввести часы и минуты вручную.
  - Чип с датой сверху: записать на другой день (подсвечивается жёлтым, пока выбран не сегодняшний день).
  - После сохранения можно нажать «Отменить» во всплывающем сообщении.
- **Записи**: все записи по дням. Нажать на запись, чтобы изменить категорию, время или дату, либо удалить её.
- **Статистика**: по дням внутри недели или сразу по неделям, с часами и процентами.
- **Категории**: создать, переименовать, сменить цвет, удалить. Категория по умолчанию тоже редактируется.

В дне считается 16 часов (сон не считаем). Если за день записано меньше 16 часов, остаток уходит
в категорию по умолчанию. Считаются дни с первой записи по сегодняшний.

Данные хранятся только на телефоне (localStorage). На вкладке «Категории» есть резервная копия:
сохранение и загрузка JSON-файла.

## Установка на телефон

Это PWA: никакой сборки не нужно, просто статические файлы.

1. Выложить репозиторий на любой статический хостинг с HTTPS. Для GitHub Pages:
   Settings → Pages → Source: **GitHub Actions**. Workflow `.github/workflows/pages.yml`
   деплоит ветку `main`.
2. Открыть ссылку на телефоне:
   - iPhone (Safari): «Поделиться» → «На экран „Домой“».
   - Android (Chrome): меню → «Установить приложение».

После этого приложение открывается с иконки на весь экран и работает без интернета.

## Локальный запуск

```sh
python3 -m http.server 8000
# открыть http://localhost:8000
```
